# Поддержка портфолио

Проект собирается Vite, но остаётся обычным статическим сайтом. Контент можно менять в HTML, а интерактивное поведение разделено на небольшие модули.

## Куда вносить изменения

- Главная страница и карточки кейсов: `dist/index.html`.
- Страницы кейсов: `dist/cases/*.html`.
- Активные светлые стили: `dist/light-design.css`.
- Галерея, фильтры, диалоги и анимации: файлы в `dist/scripts/`.
- Изображения и другие медиа: `dist/assets/`.
- Список HTML-страниц production-сборки: `vite.config.js`.

Старые CSS-файлы в `dist/` сохранены как архив предыдущих итераций и не подключаются активными страницами. Новые стили добавляйте в `light-design.css`, чтобы визуальная система оставалась в одном месте.

## Локальная проверка

```bash
npm install       # только после изменения package.json
npm run dev       # локальная разработка
npm run check     # проверка entrypoint и production-сборка
npm run preview   # просмотр собранной версии
```

После проверки отправьте изменения в ветку `main`. GitHub подключён к Vercel, поэтому новый commit запускает production-деплой автоматически.

## Как добавить новый кейс

1. Создайте HTML-файл в `dist/cases/` по структуре существующего кейса.
2. Добавьте карточку и ссылку на главной в `dist/index.html`.
3. Для галереи используйте `.source-gallery` и элементы `figure` — общий модуль `dist/scripts/gallery.js` подключится автоматически.
4. Добавьте страницу в `rollupOptions.input` в `vite.config.js`.
5. Запустите `npm run check` и проверьте мобильную ширину.
